# Screenshot Guide for Chrome Web Store

## Requirements

Chrome Web Store requires:
- **Minimum:** 1 screenshot
- **Recommended:** 3-5 screenshots
- **Dimensions:** 1280x800 or 640x400 (16:10 aspect ratio)
- **Format:** PNG or JPEG
- **Max file size:** 5 MB per image

## Recommended Screenshots

### Screenshot 1: Pin Button & Tracking Counter
**Title:** "Pin any subreddit to start tracking"

**What to show:**
- Visit reddit.com/r/programming or another active subreddit
- Show the pin button in the bottom-right corner
- Highlight the button with cursor nearby
- Include the counter badge showing post count (after pinning)

**Steps:**
1. Load the extension
2. Visit a popular subreddit
3. Pin the subreddit and scroll to collect ~25 posts
4. Take screenshot showing button and counter

## Screenshot Tips

1. **Use a clean browser profile** to avoid showing personal bookmarks or data
2. **Disable other extensions** to avoid showing them in screenshots
3. **Use sample subreddits** like r/programming, r/webdev, r/datascience (public, safe for work)
4. **Set browser zoom to 100%** for consistent sizing
5. **Take screenshots at 1280x800** (recommended size)
6. **Include only the relevant area** - crop out unnecessary browser chrome
7. **Use consistent browser theme** (light mode recommended for visibility)

## Tools for Screenshots

- **macOS:** Cmd+Shift+4 (for selection)
- **Windows:** Snipping Tool or Win+Shift+S
- **Linux:** gnome-screenshot or Spectacle
- **Browser Extension:** Nimbus Screenshot, Awesome Screenshot

## Post-Processing

After taking screenshots:
1. Crop to 1280x800 exactly
2. Check that text is readable
3. Ensure colors are vibrant and accurate
4. Save as PNG (better quality than JPEG)
5. Verify file size is under 5 MB
6. Add a 1-2px border if desired (optional)

## File Naming

Save files as:
- `screenshot-1-pin-button.png`
- `screenshot-2-popup.png`
- `screenshot-3-heatmap.png`
- `screenshot-4-filters.png`
- `screenshot-5-export.png`

Upload in this order to the Chrome Web Store.
